# الكلمات

افتح `dist/index.html` للعب أو شغّل `node preview.cjs` وافتح [المعاينة المحلية](http://127.0.0.1:4192/). افتح لوحة التحكم من أعلى الصفحة لإضافة الجولات أو تعديلها.

## حفظ الأسئلة في GitHub

1. اختر مستودعًا له فرع موجود، وأنشئ له توكن محدودًا بصلاحية **Contents → Read and write**.
2. أدخل اسم المستودع بصيغة `owner/repository` والتوكن في لوحة التحكم. اترك الفرع فارغًا لاستخدام الفرع الافتراضي.
3. أضف جولة واكتب كلماتها بالترتيب، كل كلمة في سطر. احفظ الجولة ثم اضغط **حفظ في GitHub**. يُنشأ ملف `questions.json` في جذر الفرع أو يُحدَّث إن كان موجودًا.
4. في موقع مستضاف يمكن فتح **رابط اللعبة للاعبين** لقراءة آخر نسخة من مستودع عام. يحتاج اللاعبون إلى صلاحية فتح الموقع نفسه. المستودع الخاص يدعم الإدارة بالتوكن والتجربة المحلية.

لتشغيل اللعبة على GitHub Pages، انسخ **محتويات** مجلد `dist` إلى جذر فرع النشر وفعّل Pages لذلك الفرع. اربط لوحة التحكم بنفس المستودع والفرع لتظهر تغييرات `questions.json` على رابط الموقع بعد نشر GitHub للنسخة.

يبقى التوكن في ذاكرة الصفحة حتى فصل الاتصال أو إغلاقها. تُحفظ تعديلات الجولات على هذا المتصفح، ويحتفظ تبويب اللعبة بنقاط الفريقين عند تحديثه.
